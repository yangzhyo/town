# 像素小镇 · AI 镇民日常

一个灵感源自《星露谷物语》的像素风小镇模拟面板。画布以 16px 瓦片渲染一座完整小镇（河流、湖泊、石板广场、农田、八栋建筑与森林），六位镇民按各自作息表在镇中寻路通勤；右侧木质面板同步播报时钟、天气、镇民档案与小镇日记。

## 使用方法
1. 本地启动静态服务器（例如 `npx serve` 或 `npx http-server`，也可用 VSCode Live Server）。
2. 访问工具提示的地址（如 `http://localhost:8080`）。
3. 点击画布上的镇民或左侧头像查看档案；用时钟下方的 ⏸ / ▶ / ⏩ 控制模拟速度。

## 核心特性
- **程序化像素美术**：建筑（坡屋顶、烟囱、挂牌、发光窗）、树木、人物行走精灵与头像全部由 Canvas 程序生成，无外部素材。
- **作息与寻路**：每位镇民拥有星露谷式日程表（上班、午餐、爱好、社交、回家睡觉），通过 A* 沿道路寻路，进入建筑后隐藏并点亮窗灯。
- **日夜循环**：黎明 / 白昼 / 黄昏 / 深夜的环境色渐变，夜晚路灯、窗灯发出暖色光晕，春夏夜有萤火虫。
- **四季与天气**：每 6 天换季，草地、树冠、作物随季节变色（冬季积雪、枯枝）；每天随机晴 / 多云 / 雨 / 雪，雨雪有粒子效果。
- **农田系统**：向阳农园的作物逐日生长（春防风草、夏番茄、秋南瓜），成熟后自动收获并记入日记。
- **氛围细节**：炊烟、喷泉水花、表情气泡（好友相遇会冒爱心）、悬停提示、焦点箭头。

## 手动验证
- 打开页面后确认出现完整小镇：河流与两座木桥、广场喷泉、农田、码头、八栋建筑。
- 按 ⏩ 快进观察：清晨镇民陆续出门上班，正午聚集广场，傍晚去咖啡馆，夜晚回家亮起窗灯。
- 等待跨天与跨季（每天约 2.4 分钟 ×1 速），确认日记刷新、天气变化与季节换色正常。
- 点击不同镇民头像，确认档案卡（职业、当前行为、心情、精力条）随之更新。
- 悬停画布上的镇民，确认浮动提示显示姓名与当前行为。
